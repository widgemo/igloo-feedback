# Igloo feedback

Bug reports, feature requests and questions for **Igloo**, the source-control and release companion for ServiceNow scoped apps.

- **Report a bug** or **request a feature** with the buttons in Igloo (Help and feedback in About or Settings), or choose *New issue* here.
- Feature requests can be for the free version or for **Igloo Pro** (write actions such as publish, apply and tag, coming later). Say which in the form.
- The roadmap is the pinned issue labelled `roadmap`.

## Please do not paste
Host names, instance names, app names or scopes, branch names, people's names, tokens, passwords or screenshots that show them. Igloo's **Copy support info** button produces text with all of those removed; paste that instead. This tracker is public.

Igloo reads your instances and Git hosts only from your own browser and sends nothing to us.
